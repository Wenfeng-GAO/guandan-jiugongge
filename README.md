# 掼蛋九宫格记牌练习

纯静态中文网页应用，帮掼蛋初学者练习「九宫格记牌法」。无后端、无依赖、打开即用。

## 怎么打开

直接用浏览器打开 `index.html` 即可（双击文件或拖进浏览器）。也可以在目录里起个本地服务：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 怎么玩

记牌规则：2–10 放进脑子里 3×3 的九宫格，J Q K A 单独一排，小王、大王单独记。初始张数：2–A 各 8 张，大小王各 2 张，共 108 张（两副牌）。看到牌出出去，就给对应格减 1。

**级牌**：掼蛋每局有一个级牌——当前「打几」，比如打 2，2 就是级牌。级牌最大、最常被出，也是组牌的核心。页面顶部可选级牌（默认 2），对应格子会金色高亮并带「级」角标，一眼就能看到。

**范围练习（渐进难度）**：初学直接记全牌 108 张太难，所以把练习范围分成三档，范围外的格子变灰、不能点，也不计入统计和核对：

- **只练级牌&王**（默认）：只记 级牌 + 小王 + 大王，共 12 张，适合刚学。
- **九宫格 2–10**：只记九宫格本体的 9 个点数，共 72 张。
- **全牌**：2–A + 大小王共 108 张，进阶完整练习。

切换级牌或范围会重置记数（单人模拟需重新洗牌）。

- **出牌练习**：点击范围内某个点数格子，剩余张数减 1（最低 0）。支持「撤销」上一次点击、「重置」回初始。
- **单人模拟**：点「新洗牌」只洗当前范围内的牌（如默认档共 12 张），点「翻开下一张」逐张翻牌；每翻一张，凭记忆点掉对应格子。随时点「核对答案」：范围内全对的格子变绿，记错的格子变红并标出正确张数，范围外不标色。支持「新洗牌」和「重置」。

页面顶部有「怎么玩」折叠说明。

## 文件结构

- `index.html` — 页面结构
- `styles.css` — 样式（移动端友好、触控大按钮）
- `app.js` — 界面交互
- `logic.js` — 纯逻辑（浏览器与 Node 共用），含级牌与三档范围 API：`getScopeKeys` / `createInitialCountsForScope` / `scopeInitialTotal` / `filterDeckByScope` / `createDeckForScope`，`checkAnswer` 支持只核范围内
- `check.js` — Node 自检脚本：`node check.js`，验证牌堆（108 张 / 范围过滤张数）、减数、洗牌、核对（含范围核对）、级牌与三档范围

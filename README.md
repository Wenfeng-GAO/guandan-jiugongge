# 掼蛋九宫格记牌练习

纯静态中文网页应用，帮掼蛋初学者练习「九宫格记牌法」。无后端、无依赖、打开即用。

品味稿 v6：开局扫牌（8 秒闪手牌报外剩）× 出牌闭卷（翻牌记填剩余）× 实战模拟（自动翻牌随机停闭卷作答）三关并排，作答统一用同一个 3×3 九宫格。

## 怎么打开

直接用浏览器打开 `index.html` 即可（双击文件或拖进浏览器）。也可以在目录里起个本地服务：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 三关怎么玩

首页「选一关练」并排三个入口，级牌设置在首页、三关共用。

### 开局扫牌

1. 进关自动发 27 张手牌：按点数排好，级牌（含 ♥级 逢人配）描金框，**只亮 8 秒**，到点自动盖牌、不能回看。
2. 凭记忆填 **级 / 大王 / 小王** 的外剩（外面还剩几张），点格子选中、九宫格下方数字键直选，点「核对」。
3. 每格绿 ✓ / 红 ✕（显示正确值）。有错可「只重练错的格」（换新牌只考错格），全对进「下一盘」。不计分、不挂升档。

### 出牌闭卷

1. 点「新开一盘」洗牌；再「翻开下一张」逐张记牌（**不要边看边减**）。
2. 记够后点「闭卷填剩余」：已翻列表清空，点格子选中、九宫格下方数字键直接选最终剩余，再点「核对」。
3. 核对后：正确格绿+✓，错误格红+✕并标「漏x·填y」；上方显示本盘剩余与对错。
4. **三行升档**：默认只练第 1 行（级 / 大王 / 小王）。连对 3 盘解锁第 2 行（A/K/Q），再连对 3 盘解锁第 3 行（J/10/9）。灰行预览不可点、不计分。「级」跟随当前级牌。

### 实战模拟

1. 进关自动发 27 张手牌：同开局扫牌闪 8 秒、级牌（含 ♥级逢人配）描金框，到点自动盖牌。
2. **自动翻牌**：其余 81 张由游戏按随机顺序逐张亮出（「上家出」大牌，级牌描金框），每张 1.5 秒；只显示这一张的细进度条，不显示张数和总进度，没有「下一张」「结束」按钮。
3. **随机停牌**：翻过 N 张（N 随机 10–30）时喊停，闭卷作答 级 / 大王 / 小王 的外剩（外剩 = 总张 − 手牌 − 翻过的）。
4. **三段反馈**：标题「翻了 N 张 · K 格错 ✕ / 全对 ✓」；三段「开局外剩 → 翻牌减 → 最终」，每格 ✓/✕ 原位显示并给正确值。可「下一盘」或「回看翻过的牌」。
5. **升档**：连对 3 盘 → N 从 10–30 放大到 20–50（答错连对清零，升档保持）。只存在内存，刷新即重置。

## 作答九宫格（三关通用）

第 1 行左→右：**级 / 大王 / 小王**；第 2 行：**A / K / Q**；第 3 行：**J / 10 / 9**。格子位置三关完全一致：被考的格点亮可点，未开放/锁定的格原位灰显不可点。点某格 → 九宫格**下方**弹出该格数字键（级/A–9 选 0–8，大小王选 0–2），选中数字为白实心；反馈 ✓（绿）/ ✕（红）+ 正确值显示在格子原位。

页面顶部「怎么玩」默认折叠。

## 文件结构

- `index.html` — 页面结构（首页三入口 + 三关视图）
- `styles.css` — v4 tokens 深色主题（radius≤8、琥珀强调、白实心主按钮）+ v6 作答九宫格/实战模拟样式
- `grid.js` — 统一作答九宫格组件（`GuandanGrid.createAnswerGrid`，三关共用）
- `scan.js` — 开局扫牌：8 秒闪牌 → 盖牌 → 九宫格填外剩 → 只重练错格
- `app.js` — 出牌闭卷流程与三行升档（统一九宫格作答）
- `sim.js` — 实战模拟：闪手牌 → 自动翻牌 → 随机停 → 闭卷作答 → 三段反馈
- `logic.js` — 纯逻辑（浏览器与 Node 共用）：`dealScanHand` / `dealSimRound` / `applySimStreak` / `SIM_FLIP_MS` / `numberOptions` / `isWild` 等
- `check.js` — Node 自检：`node check.js`
- `test/scan.test.js` / `test/sim.test.js` — 开局扫牌 / 实战模拟逻辑测试

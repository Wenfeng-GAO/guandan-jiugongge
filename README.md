# 掼蛋九宫格记牌练习

纯静态中文网页应用，帮掼蛋初学者练习「九宫格记牌法」。无后端、无依赖、打开即用。

## 怎么打开

直接用浏览器打开 `index.html` 即可（双击文件或拖进浏览器）。也可以在目录里起个本地服务：

```bash
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 怎么玩

记牌规则：2–10 放进脑子里 3×3 的九宫格，J Q K A 单独一排，小王、大王单独记。初始张数：2–A 各 8 张，小王和大王各 2 张，共 108 张（两副牌）。看到牌出出去，就给对应格减 1。

- **出牌练习**：点击某个点数格子，剩余张数减 1（最低 0）。支持「撤销」上一次点击、「重置」回初始。
- **单人模拟**：点「新洗牌」洗好 108 张牌，点「翻开下一张」逐张翻牌；每翻一张，凭记忆在格子上点掉对应点数。随时点「核对答案」：你的记数和真实剩余对比，全对的格子变绿，记错的格子变红并在右上角标出正确张数。支持「新洗牌」和「重置」。

页面顶部有「怎么玩」折叠说明。

## 文件结构

- `index.html` — 页面结构
- `styles.css` — 样式（移动端友好、触控大按钮）
- `app.js` — 界面交互
- `logic.js` — 纯逻辑（浏览器与 Node 共用）
- `check.js` — Node 自检脚本：`node check.js`，验证洗牌（108 张）、减数、核对逻辑

怎么玩

开局扫牌：进关自动发 27 张手牌，按点数排好、级牌（含 ♥级 逢人配）描金框，只亮 8 秒，到点自动盖牌、不能回看。凭记忆填 级 / 大王 / 小王 的外剩（外面还剩几），点格子选中、下方数字键直选，点「核对」。

扫牌反馈：每格绿 ✓ / 红 ✕ 并显示正确值。有错可「只重练错的格」（换新牌只考错格），全对进「下一盘」。不计分、不挂升档。

出牌闭卷：点「新开一盘」洗牌，「翻开下一张」逐张记牌（不要边看边减）。「闭卷填剩余」后点格子选中，用下方数字键直接选剩余，再点「核对」。

三行升档（出牌闭卷）：默认只练第 1 行（级 / 大王 / 小王）。连对 3 盘解锁第 2 行（A/K/Q），再连对 3 盘解锁第 3 行（J/10/9）。灰行预览不可点、不计分。「级」跟随当前级牌，三关共用上方设置。

实战模拟：8 秒闪手牌后盖住，其余牌由游戏自动逐张翻（每张 1.5 秒，只显示这一张的细进度条）。翻过 N 张（随机 10–30）喊停，按「外剩 = 总张 − 手牌 − 翻过的」闭卷作答。反馈分三段：开局外剩 → 翻牌减 → 最终。连对 3 盘 → N 放大到 20–50；满档后顶栏只显示「已满档 20–50」。错一盘不降档，连错两盘退回 10–30。

作答九宫格（三关通用）：第 1 行 级/大王/小王，第 2 行 A/K/Q，第 3 行 J/10/9。未开放的格原位灰显不可点；点被考的格，九宫格下方弹出数字键（级/A–9 选 0–8，王选 0–2）。
